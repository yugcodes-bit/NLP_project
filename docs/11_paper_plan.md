## 1. Claims (each needs its evidence row)

| # | Claim (draft wording — adjust to results) | Evidence |
|---|---|---|
| C1 | We release a harmonised multi-label + intensity Hinglish emotion benchmark built from N sources, plus a new independent gold test set of M items with α = x | Data section, datasheet |
| C2 | Training on the harmonised data improves cross-dataset generalisation over the best single source by Δ macro-F1 (p < .05) | A8 table + heatmap |
| C3 | Code-mixed-pretrained encoders (HingRoBERTa-Mixed) outperform / match multilingual encoders by Δ | Main table, significance |
| C4 | All models lose Δ_p macro-F1 under realistic transliteration/script perturbations; targeted augmentation recovers r% of the loss | Robustness figure |
| C5 | Temperature scaling reduces ECE from a to b; selective prediction at coverage c raises precision to d | Calibration figure, risk–coverage |
| C6 | A distilled int8 student (S MB) retains p% of teacher macro-F1 and runs in-browser in t ms | Efficiency table |
| C7 | Fine-tuned encoders outperform/compare to zero/few-shot LLMs at a fraction of cost/latency | LLM rows + cost table |

If a result goes the other way, the claim is rewritten, not dropped.

## 2. Outline

1. **Introduction** (0.75 p) — Hinglish emotion matters; fragmentation + robustness + deployment gaps; contributions list (C1–C7).
2. **Related Work** (0.75 p) — code-mixed NLP & benchmarks; Hinglish emotion datasets/systems; multilingual/code-mixed encoders; calibration & robustness in NLP; LLMs vs fine-tuned classifiers.
3. **Data** (1.25 p)
   3.1 Sources & licenses (table) · 3.2 Label harmonisation (mapping table, decisions) · 3.3 Dedup & splits · 3.4 Gold test set: sourcing, guidelines, IAA · 3.5 Statistics (script mix, CMI distribution)
4. **Methods** (1 p) — models (baselines, encoders, LLM prompting), heads & losses, calibration/thresholds/abstention, augmentation, distillation & quantisation.
5. **Experimental Setup** (0.5 p) — seeds, budgets, metrics, significance tests, hardware.
6. **Results** (2 p)
   6.1 Main comparison (Table) · 6.2 Cross-dataset generalisation (heatmap) · 6.3 Robustness (bars) · 6.4 CMI & script slices · 6.5 Calibration & selective prediction · 6.6 Efficiency & student · 6.7 LLM comparison
7. **Analysis** (0.75 p) — error taxonomy, qualitative examples, explanation faithfulness check.
8. **Deployment** (0.25 p) — architecture, privacy design, latency, cost (₹0).
9. **Conclusion** (0.25 p)
- **Limitations** (required, unnumbered) — from `10` §4.
- **Ethics Statement** — data consent/licensing, annotator welfare, misuse (surveillance, mental-health), privacy-by-design.
- Appendix: full mapping tables, annotation guidelines summary, hyper-parameters, per-label results, prompts, perturbation rules, extra examples.
